H · APP DEPENDENCIES   /   I · NAMING
REQUIRED FUNCTIONALITY

Digital delivery — Shopify "Digital Downloads" app (free) for STL files.
Quote file uploads — a form app with attachments (or custom endpoint); Shopify's native contact form can't take files.
Spam protection — hCaptcha/reCAPTCHA via the form solution; no visible badge.
Email notifications — Shopify native + form-app routing to the studio inbox.
Customer accounts — optional at launch; enable "accounts optional".
Nothing else — no reviews, upsell, or popup apps.
